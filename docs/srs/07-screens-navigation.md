# 7. מסכי מערכת וניווט

מסכי PG-001 עד PG-011 נגזרו ישירות מהסקיצות. מסכי PG-012 ואילך הם מסכים תומכים הנדרשים מהקונספט העסקי והחידודים שאושרו, אך לא הופיעו כסקיצה מלאה.

**עיצוב:** השפה החזותית המחייבת נמצאת ב-[`docs/design/`](../design/README.md): כיוון, tokens ומוקאפים (NFR-USAB-004). הסקיצות הן קונספט ([נספח A](appendix-a-sketches.md)). **דפוסי האינטראקציה** (NFR-USAB-004, אפיק 19.10.2026) מחייבים כל מסך: עמוד נפרד רק ליעד — פרופיל, קבוצה, פוסט בודד, הגדרות וצ'אט במובייל — וכל פעולה אחרת מתבצעת במקום.

## 7.1 Bottom Navigation

Regular User משתמש בניווט התחתון המוגדר בסקיצות. Professional User לא יקבל Home Tracking; יעד הבית שלו הוא Professional Dashboard. **הניווט התחתון של Professional** (החלטת אפיק מ-21.10.2026; OP-016 נסגר): בית (לוח הבקרה) · פיד · שיחות (מרכז השיחות, עם מונה השיחות שיש בהן הודעות שלא נקראו, ⭐ OP-073) · פרופיל (הפרופיל המקצועי). **תוויות בממשק:** בית · חנות · פיד · יועצים · פרופיל. ללשונית הפיד אייקון של הלוגו, וללשונית הפרופיל תמונת המשתמש. **ב-MVP** מוצגים למשתמש רגיל בית, חנות, פיד, יועצים ופרופיל ("יועצים" ו"חנות" נוספו כשהיעדים שלהם נבנו, 21.10.2026; §2.5). **בדסקטופ,** מרוחב 1024px, אותם יעדים מוצגים ב-rail אנכי בצד ההתחלה (NFR-USE-001) (החלטות מ-11.10.2026).

## 7.2 מסלולי מעקב ותפריטי Tracker

הסקיצה של עמוד הבית מציגה שלושה מסלולי מעקב: ילד/ה, הריון ולידה, מחזור וביוץ. היא מציגה גם תפריט Tracking ("יומן פעולות") עם שמונה סוגי מעקב: הנקה, בקבוק, שינה, חיתול, תרופה, גדילה, חיסון ואמבטיה (האריח השמיני אושר ב-11.10.2026; OP-007 נסגר). בממשק האריחים מוצגים ברשת ולא בשורה גלילה.

> לכל Tracker ייפתח עמוד ייעודי. השדות של כל Tracker, הגרפים לפי תקופה והנראות (רק המשתמש עצמו) — FR-TRACK-001 (OP-008 נסגר, החלטת אפיק מ-18.10.2026); Tracker הנקה — FR-TRACK-002.

## 7.3 Top Bar ומנגנונים גלובליים

Top Bar הוא רכיב גלובלי בתוך מעטפת האפליקציה. ב-Regular/Professional סדר הפעולות ב-RTL הוא Hamburger בצד ימין ולצידו הלוגו, Global Search במרכז, Chat ו-Notification Bell בצד שמאל.

### 7.3.1 Hamburger / Side Menu

Side Menu אינו משכפל את ה-Bottom Navigation. Regular: My Groups, Friends, Following Professionals, Account/Privacy/Notification/Terms דרך מסך ההגדרות, Help/Support Request, כללי הקהילה (PG-049), פנייה למוקד רפואי (PG-047), שאלות לשחזור סיסמה (PG-052), החלפת סיסמה (PG-054), שיתוף Nestly (FR-FEED-007) ו-Logout; מוצגים רק יעדים זמינים, בסדר שב-FR-MENU-001. Professional: My Groups, הפרופיל המקצועי, המאמרים שלי, ההצעות שלי, Professional Promotion & Analytics, Billing/Promotions, Following Professionals, מדריך בעלי המקצוע, Settings, Help/Support ו-Logout, בלי Friends (החלטת אפיק מ-21.10.2026; אין Verification Status — OP-005 נסגר). Admin/Moderator הם חשבונות מערכת; Admin רואה את כל כלי הניהול ו-Moderator רק יעדים לפי Permission Keys.

### 7.3.2 Global Search

החיפוש מחזיר People, Groups ו-Posts. כל Regular User פעיל מופיע ב-People Search לפחות עם שם, תמונה ומידע ציבורי בסיסי. המשתמש יכול לקבוע אם פרופילו פתוח ל-non-Friends; במצב Restricted non-Friend אינו רואה מעבר למידע הבסיסי. Professional מסומן כ-Professional. Private Group ניתן לגילוי אך תוכנו מוגן.

### 7.3.3 Notifications

Bell מציג unread count ופותח Dropdown. כל Notification כולל Type, Actor/System, Text, Timestamp, Read/Unread ו-Target. מסך ההתראות מציג היסטוריה מלאה ו-Mark all as read. אייקון Settings פותח Multi-select/Toggles לסוגי אירועים; Security/Critical אינם ניתנים לכיבוי ב-In-App. לכל Group ניתן לבחור All / Highlights / Off. בשלב Web ההתראות החברתיות/מערכתיות הן In-App; בשלב Mobile ניתן גם Push לקטגוריות מאופשרות ובכפוף להרשאת מערכת ההפעלה. Email/SMS אינם ערוץ להתראות החברתיות/המסחריות השוטפות.

### 7.3.4 Chat

Chat Icon מציג unread count ו-Dropdown של Recent Conversations/Requests. Friends פותחים Chat ישיר; non-Friends שולחים Regular Chat Request ל-Accept/Decline. Conversation קיימת ממשיכה לאחר Remove Friend. Offer Help נשמר באזור Requests. תגובת Support מופיעה כשרשור בשם “Support” ומוגבלת לפנייה. Chat Block משפיע רק על הודעות.

## 7.4 Relationship Model

Regular↔Regular משתמשים ב-Friends בלבד כ-Relationship Model, אך Friendship אינה תנאי לבקשת שיחה: non-Friend יכול לשלוח Regular Chat Request והנמען בוחר Accept/Decline. Friends פותחים Chat ישיר. Professional Profile אינו מקבל Friend Requests; הקשר אליו Follow. חסימת משתמש (FR-REL-002) הדדית, מסתירה פוסטים, תגובות ופרופיל בשני הכיוונים ומסיימת את ה-Friendship.

## 7.5 Groups

Public Group: ניתן לחיפוש, תוכן גלוי למשתמשים מחוברים, Join מיידי ורק Members מפרסמים/מגיבים. Private Group: ניתן לחיפוש לפי פרטי הקבוצה אך תוכנו מוסתר ללא Membership; Join דורש Owner/Admin. כל Regular/Professional רשאי ליצור Group ולהפוך ל-Owner. היררכיה: Owner > Admin > Group Moderator > Member. גישת Moderator מערכת לתוכן Private דורשת PRIVATE_GROUP_MODERATE דרך כלי ניהול.
