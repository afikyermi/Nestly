# 5. דרישות פונקציונליות · Search — חיפוש

## FR-SEARCH-001 — חיפוש

| שדה | הגדרה |
|---|---|
| סטטוס | מאושר; חיפוש People (Regular) ו-Posts זמין; Groups ו-Professional ב-People Search ייכללו עם הקבוצות ופרופילי המקצוע |
| Actor | Regular User / Professional User |
| תיאור | המערכת תאפשר Global Search מתוך מרכז ה-Top Bar עבור Posts, Groups ו-People. תוצאות ראשוניות יוצגו ב-Dropdown מחולק לפי סוג, ו-“הצגת כל התוצאות” יעביר למסך תוצאות חיפוש. |
| תנאים מוקדמים | משתמש Regular או Professional מחובר. |
| קלט / Trigger | מחרוזת חיפוש מתוך שדה החיפוש הגלובלי או בחירת Filter במסך תוצאות חיפוש. |
| תהליך מערכת | המערכת תחפש People, Groups ו-Posts. כל Regular User פעיל יופיע ב-People Search לפחות עם שם, תמונה ומידע ציבורי בסיסי; Professional יסומן ככזה. פתיחת Regular Profile על ידי non-Friend כפופה ל-Regular Profile Visibility. Group יכול להופיע בחיפוש, אך Post מתוך Private Group מוצג רק ל-Member. חריגי Admin/Moderator זמינים רק דרך כלי ניהול ולא דרך Global Search. People Search מוגבל ל-60 חיפושים בשעה לכל חשבון, כ-Configuration (NFR-SEC-006; OP-035 נסגר, החלטת אפיק מ-18.10.2026); מעבר למגבלה מוצגת הודעה אחת, "הגעתם למספר החיפושים לשעה. אפשר להמשיך לחפש פוסטים, ולחפש אנשים בעוד זמן מה", והחיפוש בפוסטים ממשיך לפעול. חיפוש קצר משתי אותיות, ריק או ארוך מ-100 אותיות אינו מחזיר תוצאות ואינו נספר; אין רשימת משתמשים בלי מחרוזת חיפוש. Admin, Moderator וחשבון שאינו פעיל אינם מופיעים ב-People Search. Posts נשלפים לפי הרשאות הצופה בלבד (הסתרה, קהל, Friends בלבד), ורק אחר כך מדורגים. הקלדה בשדה החיפוש מפעילה חיפוש רק לאחר הפסקה בהקלדה ומשתי אותיות, ותוצאות אותו טקסט משותפות לחלונית ולמסך התוצאות, כדי שטקסט אחד ייספר פעם אחת. כל חיפוש שנענה שומר את הנושא שזוהה בלבד (Intent Signal, FR-ALG-008), לא את הטקסט, וכל נושא נשמר לכל היותר פעם ביום; הטקסט אינו מופיע בכתובת של מסך התוצאות ואינו נשלח בכתובת לשרת. |
| פלט | Dropdown עם תוצאות מובילות לפי People / Groups / Posts, וקישור למסך תוצאות חיפוש עם Tabs: All / People / Groups / Posts. |
| מצב לאחר ביצוע | בחירת תוצאה מבצעת Deep Link לאחר Authorization. Regular User אינו יכול להסתיר את עצם קיומו מ-People Search. |
| בעל אחריות לוגי (Page / Feature) | מסך תוצאות חיפוש / חיפוש גלובלי / שדה החיפוש הגלובלי / חלונית נפתחת (Dropdown) |
