## FR-MENU-002 — פנייה למוקדי רפואה

| שדה | הגדרה |
|---|---|
| סטטוס | מאושר — החלטת אפיק מ-16.10.2026. המוקד של מאוחדת — ממתין לאישור אפיק |
| Actor | Regular User / Professional User |
| תיאור | עמוד קבוע עם כפתורי חיוג למוקדי רפואה: מד"א 101 ומוקדי האחיות של ארבע קופות החולים. המספרים נבדקים מול מקור רשמי. העמוד מציג "לא תחליף לטיפול רפואי. במצב חירום — 101". `/medical-hotlines`, כותרת "פנייה למוקד רפואי" (גם שם הפריט בתפריט). השורה "לא תחליף לטיפול רפואי. במצב חירום — 101" מופיעה מעל הרשימה. חמישה קישורי חיוג, לפי הסדר: מד"א, ואחריו הקופות בסדר האלף-בית — כללית, לאומית, מאוחדת, מכבי — כך שאף קופה אינה מועדפת. כל קישור מציג את שם השירות ואת המספר, כך שגם במחשב אפשר לקרוא ולחייג. קופה שהאתר הרשמי שלה אינו מציין מוקד אחיות מקבלת את המוקד הטלפוני 24/7 שהיא מפרסמת, עם השם שלו (מאוחדת — "מוקד טלפוני 24/7"; **ממתין לאישור אפיק**, כי ההחלטה של 16.10 מדברת על מוקדי אחיות). המספרים נבדקו מול האתרים הרשמיים ב-19.10.2026; הם קבועים בעמוד ואינם ניתנים לעריכה מממשק הניהול. |
| תנאים מוקדמים | משתמש מחובר. |
