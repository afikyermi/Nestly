## FR-PRIV-001 — פרטיות פרופיל Regular מול non-Friends

| שדה | הגדרה |
|---|---|
| סטטוס | מאושר (17.10.2026) |
| Actor | Regular User / System |
| תיאור | Regular User תמיד ניתן לאיתור ב-People Search. המשתמש יכול לקבוע אם הפרופיל פתוח לצפייה של מי שאינו Friend. **Restricted:** non-Friend רואה רק את ה-Basic Public Profile (§1.4): שם, תמונה, Journey Summary ללא גילאים, Friends ו-Friends משותפים, ופעולת שליחת הודעה בכפוף ל-FR-CHAT-002. **Open:** non-Friend רואה את כל הפרופיל. מידע על ילדים והריון מוצג רק כ-Journey Summary מלא: מספר ילדים, גילאים, ו"בהריון" אם קיים, ללא פרטים. אם אין ילדים ואין הריון — המשפט שמוגדר ב-Journey Summary (§1.4), אלא אם המשתמש הסתיר אותו במתג בהגדרות הפרטיות. Tracker Data אינו מוצג. **Friend** רואה את תצוגת ה-Open בשני המצבים, ומידע על ילדים והריון גם לו רק כ-Journey Summary (החלטת אפיק מ-17.10.2026). **ברירת המחדל: Open**, לחשבונות חדשים ולקיימים; המשפט מוצג, ויום ההולדת בהתראות לחברים מאושר (החלטת אפיק מ-16.10.2026). |
| תנאים מוקדמים | Regular User פעיל; צופה מחובר שאינו Friend. |
| קלט / Trigger | שינוי Profile Visibility במסך ההגדרות, או פתיחת Regular Profile מתוצאת חיפוש, מרשימת Friends או מקישור לפרופיל. |
| תהליך מערכת | ניהול ההגדרות שומר Open/Restricted, ואת מתג ההסתרה של משפט ה-Journey Summary (ברירת מחדל: מוצג). Search תמיד מחזיר את ה-Basic Public Profile. Restricted מגביל את הפרופיל ל-Basic Public Profile. Open מאפשר צפייה בכל הפרופיל, אך מידע על ילדים והריון מוצג רק דרך Journey Summary (§1.4): שמות ילדים, תאריכי לידה, שבוע הריון ותאריך לידה צפוי אינם מוצגים ל-non-Friend בשום מצב, ו-Tracker Data לעולם אינו מוצג ל-non-Friend. Professional נחשב non-Friend, ורואה **בדיוק** מה ש-Regular non-Friend רואה (OP-020). התראת יום הולדת של ילד נשארת כפופה ל-BR-037. **תוכן הפרופיל ב-Open:** השם, מין ההורה ("מעדיפים לא לציין" מוצג כך; כשלא צוין — לא מוצג) וה-Journey Summary המלא. הגיל מחושב מתאריך הלידה, בשנים ובחודשים מלאים לפי התאריך בישראל, ותאריך הלידה עצמו אינו נמסר לצופה; תאריך לידה עתידי נקרא כפחות מחודש. הגילאים מוצגים בסדר שבו הבעלים רואה את הילדים (סדר ההוספה). נוסח הגיל, בשנים ובחודשים, בלי "בן"/"בת" ובלי "גיל" (החלטת אפיק מ-17.10.2026): "פחות מחודש", "חודש", "חודשיים", "4 חודשים", "שנה", "שנה וחודש", "שנה ו-3 חודשים", "שנתיים", "שנתיים ו-5 חודשים", "3 שנים", "3 שנים ו-5 חודשים", "11 שנים". רשימת ה-Friends של המשתמש ורשימת ה-Friends המשותפים מוצגות בשני המצבים ולכל צופה, כל רשומה שם ומזהה בלבד; Friend שאינו פעיל אינו מופיע. משתמש מושעה, חסום, Professional או מזהה שאינו קיים — "הפרופיל לא זמין", אותה תשובה לכל הסיבות. קריאת פרופיל של אחר עוברת בנתיב מאושר יחיד, שגם סופר את הפתיחה ורושם את אירוע ה-Security של הצופה עצמו (החלטת אפיק מ-17.10.2026). כל פתיחה נספרת בהגבלת הקצב (NFR-SEC-006). **Profile/Deep Link:** לכל Regular כתובת פרופיל `/u/<מזהה>`, שהמזהה בה אינו ניתן לניחוש; במסך החברים "העתקת הקישור לפרופיל שלי" מעתיק אותה (PG-036), ומבקר שפותח אותה עובר דרך ההתחברות (FR-AUTH-004). הכתובת של המשתמש עצמו פותחת את הפרופיל שלו (FR-PROFILE-001) ואינה נספרת (17.10.2026). |
