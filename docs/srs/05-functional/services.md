## FR-SERV-005 — Offer Help בעקבות פוסט

| שדה | הגדרה |
|---|---|
| סטטוס | מאושר; עודכן 24.10.2026 (OP-010 עודכן, OP-038 נסגר) |
| Actor | Professional User |
| תיאור | בעל מקצוע יוכל לשלוח Message Request / Offer Help למשתמש רגיל בעקבות פוסט מסוים שפרסם. **מדיניות הפנייה היזומה** (החלטות אפיק מ-18.10.2026 ומ-24.10.2026, OP-010): פנייה יזומה רק כ"הצעת עזרה" על פוסט, אחת לכל פוסט, ולכל היותר 100 ב-24 שעות לכל בעל מקצוע. אין הודעות פרסום יזומות; הפרה מטופלת בדיווח ובמדרג הרגיל (FR-MOD-001, BR-074). **על איזה פוסט:** כל פוסט פעיל של משתמש רגיל שבעל המקצוע רשאי לראות לפי כללי הפיד — פוסט ל"כולם", פוסט אנונימי (זהות הכותב מוסתרת עד Accept, AC-147), פוסט על אובדן, ופוסט בקבוצה שבעל המקצוע חבר בה. לא פוסט "חברים בלבד", לא פוסט בקבוצה פרטית שאינו חבר בה, לא שיתוף, לא פוסט של בעל מקצוע (⭐ OP-073), ולא פוסט שאינו אנונימי כשיש חסימה בין השניים. אין סימון "מבקש עזרה" בפוסט ואין להורה מתג להצעות (OP-038 נסגר). **מאיפה:** "הצעת עזרה" בשורת הפעולות של כרטיס הפוסט בפיד ובעמוד הפוסט, ובמסך "בקשות עזרה" (PG-057), שמציג את הפוסטים האחרונים בתחום של בעל המקצוע (⭐ OP-072); לוח הבקרה מציג את הראשונים שבהם וכמה הצעות נשלחו היום. בחלון ההצעה נאמר שרק אישור פותח שיחה, ובפוסט אנונימי — שהזהות תיחשף רק אם יאשרו. בעל המקצוע גם מגיב ועושה לייק על כל פוסט שהוא רשאי לראות (FR-FEED-003). |
| תנאים מוקדמים | בעל המקצוע מחובר ופעיל; הפוסט פעיל, שייך למשתמש רגיל ובעל המקצוע רשאי לראות אותו (כאמור); לא נשלחה כבר פנייה מאותו בעל מקצוע עבור אותו פוסט; ובעל המקצוע לא שלח 100 פניות ב-24 השעות האחרונות. |
| קלט / Trigger | "הצעת עזרה" מכרטיס הפוסט, מעמוד הפוסט או מ"בקשות עזרה", והודעה ראשונה. |
| תהליך מערכת | יצירת ProfessionalOutreachRequest המקושר לפוסט, לבעל המקצוע ולמשתמש היעד. אם הפוסט אנונימי (FR-FEED-005), זהות המחבר אינה נחשפת לבעל המקצוע עד שהמחבר מאשר את הבקשה. |
| פלט | Message Request אחד נשלח למשתמש הרגיל; בכרטיס, בעמוד הפוסט וב"בקשות עזרה" מוצג לבעל המקצוע "נשלחה הצעה" במקום "הצעת עזרה". |
| מצב לאחר ביצוע | לא נפתח Chat מלא עד שהמשתמש הרגיל מאשר את הפנייה. |
| בעל אחריות לוגי (Page / Feature) | פנייה יזומה של בעל מקצוע |
