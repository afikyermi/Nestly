## FR-SERV-009 — Chat Block ודיווח

| שדה | הגדרה |
|---|---|
| סטטוס | מאושר ברמת Chat Block; מדיניות הסלמה בדיווחים חוזרים עדיין TBD |
| Actor | Regular User / Professional User |
| תיאור | המערכת תאפשר לחסום המשך הודעות Chat מצד משתמש אחר ולבצע Unblock. Chat Block אינו חסימה גלובלית: אינו מסתיר חשבון, אינו מסיר Friendship/Follow ואינו מונע אינטראקציות שאינן Chat. Report נשמר כמנגנון Moderation נפרד. |
| תנאים מוקדמים | קיימת Conversation/Message Request או אפשרות Messaging בין החשבונות. |
| קלט / Trigger | Block Chat / Unblock Chat / Report. |
| תהליך מערכת | שמירת ChatBlock כמצב Messaging נפרד. כל עוד פעיל, לא ניתן לשלוח הודעות חדשות בערוץ Chat; Unblock מחזיר אפשרות Messaging לפי שאר כללי ההקשר. Report נשמר בנפרד. |
| פלט | אישור Chat Block/Unblock או Report. |
| מצב לאחר ביצוע | Chat Block משפיע רק על Messaging ואינו משנה קשרים/נראות במערכת. Report escalation יוגדר בנפרד. |
| בעל אחריות לוגי (Page / Feature) | MessagingFeature / ModerationFeature |
