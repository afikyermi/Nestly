## FR-AUTH-005 — כניסה והרשמה עם Google

| שדה | הגדרה |
|---|---|
| סטטוס | מאושר (13.10.2026) |
| Actor | Guest |
| תיאור | המערכת תאפשר "המשך עם Google" במסכי Welcome, Login והרשמה, כדרך שוות-ערך לאימייל וסיסמה. מ-Google נשמר האימייל בלבד; התמונה אינה מיובאת (החלטה מ-13.10.2026). משתמש חדש ממשיך לשלב 1 של ההרשמה (FR-REG-002) ולאישור התנאים והצהרת הגיל (FR-REG-004), בלי סיסמה. |
| תנאים מוקדמים | אין Session פעיל. |
| קלט / Trigger | בחירת "המשך עם Google" והסכמה במסך של Google. |
| תהליך מערכת | אימות מול Google דרך Supabase Auth. ייחודיות האימייל בכל החשבונות נשמרת (BR-045). שיוך בין כניסת Google לחשבון קיים עם אותו אימייל אינו מתבצע בלי הוכחה שהחשבון שייך למבקש; הכלל המדויק נקבע בתכנון הפיצ'ר ונבדק ב-CRITIC (סיכון השתלטות מוקדמת, כי האימייל אינו מאומת בהרשמה). ההודעות אינן חושפות קיום חשבון. |
| פלט | חשבון קיים: Session פעיל ומעבר לפיד. משתמש חדש: המשך ההרשמה. |
| מצב לאחר ביצוע | המשתמש מחובר, או בתהליך הרשמה. |
| בעל אחריות לוגי (Page / Feature) | WelcomePage / LoginPage / GoogleSignInFeature |
