# 5. דרישות פונקציונליות · Marketplace

## FR-MKT-001 — צפייה ב-Marketplace

| שדה | הגדרה |
|---|---|
| סטטוס | מאושר/נגזר מהקונספט; פורט 21.10.2026; עודכן 26.10.2026 (I12 ב', החלטות אפיק מ-21.10.2026) |
| Actor | Regular/Professional |
| תיאור | המערכת תציג עמוד Marketplace כאוסף פרסומי מוצרים. העמוד יכלול Marketplace Listings שמשתמשים רגילים מפרסמים לצורך מכירה/מסירה, וכן תוכן מסחרי/מוצרים ממומנים לפי המודל העסקי. קופונים ו-Affiliate אינם ב-MVP; בהצגה למרצה מוצגים קופונים להדגמה כמוצרים ממומנים רגילים, עם הסימון "ממומן" ובלי סימון "דוגמה", ונמחקים לפני ההשקה — תוכן Marketplace רגיל שנוצר דרך המוצר, בלי קוד ייעודי (OP-023 נסגר; החלטות אפיק מ-18.10.2026 ומ-21.10.2026; §11). **ב-v1 (21.10.2026):** העמוד נפתח מ"חנות" בניווט התחתון של משתמש רגיל (§7.1). **Professional** פותח אותו מ"חנות" שבתפריט (FR-MENU-001) לצפייה ולפנייה למוכרים בלבד: אין לו "פרסום מודעה" ו"המודעות שלי", וכניסה ישירה לטופס מודעה מציגה "רק חשבון הורה יכול לפרסם מודעה" (החלטת אפיק מ-21.10.2026). אפשר לחפש מילים בכותרת, לסנן לפי קטגוריה, עיר או אזור (§12), מצב, מחיר מרבי ו"רק למסירה", ולבחור סדר: "מתאים לי" (נושאי החיפוש של המשתמש, FR-ALG-008, ואחריהם טריות), "החדשות קודם" או "מהזול ליקר". מוצגות רק מודעות פעילות, שלא הוסתרו ושלא פגו, של חשבון פעיל, בלי חסימה בין המשתמשים (FR-REL-002); מודעה שהמשתמש דיווח עליה לא מוצגת לו. עד שלושה מוצרים ממומנים מוצגים בנפרד מהמודעות, עם הסימון "ממומן" (BR-005), ומוצרים בקטגוריה שנבחרה קודמים. מודעה שסומנה "נמכר/נמסר" אינה מוצגת (BR-091). "המודעות שלי" מציג למפרסם את כל המודעות שלו, גם שנמכרו, שהוסתרו על ידי הצוות ושפגו (עד שנמחקו, BR-090). **הצוות:** בעל MARKETPLACE_MODERATE רואה את כל המודעות, ומסתיר או מחזיר מודעה עם סיבה שנרשמת ב-Audit Log; הצוות לא עורך ולא מוחק מודעה. דיווח על מודעה מטופל בתור הדיווחים באותה הרשאה, ומציג את המודעה כפי שהיא עכשיו (גם התיאור), את הכותרת בזמן הדיווח, את כל הדיווחים עליה ואת כרטיס המפרסם (החלטת אפיק מ-21.10.2026). |
| תנאים מוקדמים | משתמש מחובר. |
| קלט / Trigger | Marketplace Listings, Sponsored Products/Content ונתוני קידום. |
| תהליך מערכת | טעינת פריטים והצגתם לפי סוג המקור והקידום. |
| פלט | רשימת פריטי Marketplace עם זיהוי ברור של סוג הפרסום. |
| מצב לאחר ביצוע | המשתמש יכול לבחור פריט/מוצר. |
| בעל אחריות לוגי (Page / Feature) | ניהול ה-Marketplace |

## FR-MKT-002 — יצירת Marketplace Listing

| שדה | הגדרה |
|---|---|
| סטטוס | מאושר; עודכן 18.10.2026 (OP-012 נסגר); פורט 21.10.2026; עודכן 26.10.2026 (החלטות אפיק מ-21.10.2026: OP-052 ו-OP-054 נסגרו; ⭐ OP-082) |
| Actor | Regular User |
| תיאור | המערכת תאפשר למשתמש רגיל ליצור Marketplace Listing נפרדת מפוסט קהילתי רגיל, לצורך מכירה או מסירה של מוצר. **כללי המסחר** (החלטת אפיק מ-18.10.2026, OP-012): מודעה כוללת כותרת, קטגוריה, מצב, מחיר או "למסירה", עיר ותמונות. המוכר מסמן "נמכר/נמסר", ומודעה פגה אחרי 60 יום. ההתקשרות בצ'אט בלבד, בלי תשלום באתר (BR-069). **השדות ב-v1 (21.10.2026; עודכנו 26.10.2026 לפי החלטות אפיק מ-21.10.2026):** כותרת של 2 עד 80 תווים; תיאור, לא חובה, עד 1,000 תווים; קטגוריה — עגלות, כיסאות בטיחות, ריהוט, ביגוד, צעצועים, האכלה, רחצה וטיפוח, הריון, ספרים, מכשירי חשמל, אחר; מצב — חדש, כמו חדש, טוב, משומש; מחיר בשקלים שלמים, 0 עד 100,000, ו-0 מוצג "למסירה" — בטופס, כשמוקלד 0, מופיע "המודעה תוצג "למסירה"" (VAL-013; OP-052 נסגר); עיר או אזור מהרשימה (§12, OP-050); עד 6 תמונות (VAL-041), שכל אחת נבדקת לפני שהיא מוצגת לאחרים (BR-076). רק משתמש רגיל פעיל מפרסם; חשבון מקצועי, Admin ו-Moderator לא. **אחרי הפרסום:** המפרסם עורך את המודעה, מוסיף ומסיר תמונות (עד 6 בסך הכול), מסמן "נמכר/נמסר" ומחזיר למכירה, ומוחק. מחיקה מוחקת את המודעה מיד, גם כשיש עליה דיווח פתוח; הדיווח נשאר לצוות עם הכותרת שנשמרה בו (האם מודעה שדווחה נשמרת מוסתרת, כמו פוסט — OP-053). המפרסם לא מאריך את התפוגה. **נמכר:** מודעה שסומנה "נמכר/נמסר" יוצאת מה-Marketplace ונשמרת למפרסם ב"המודעות שלי" ולצוות, עד שהמפרסם מוחק אותה או שהחשבון נמחק (BR-091); אחרי 60 יום מפרסומה היא לא חוזרת למכירה (ERR-054). **פגה:** מודעה שפגה בלי שסומנה "נמכר/נמסר" נמחקת עם התמונות שלה (BR-090); עד אז היא מוצגת רק למפרסם ולצוות. המפרסם רואה בדף המודעה עד מתי היא מוצגת ושאז היא נמחקת (OP-054 נסגר, החלטת אפיק מ-21.10.2026). |
| תנאים מוקדמים | משתמש רגיל מחובר. |
| קלט / Trigger | כותרת, תיאור (לא חובה), קטגוריה, מצב, מחיר (0 = "למסירה"), עיר ותמונות (VAL-013, VAL-041). |
| תהליך מערכת | ולידציה ושמירת Listing עם sourceType של משתמש רגיל. |
| פלט | Marketplace Listing חדשה. |
| מצב לאחר ביצוע | הפריט מופיע ב-Marketplace בהתאם לכללי החשיפה, עד שסומן "נמכר/נמסר" (נשמר, BR-091) או עד שפג אחרי 60 יום (נמחק, BR-090). |
| בעל אחריות לוגי (Page / Feature) | ניהול ה-Marketplace |

## FR-MKT-005 — פתיחת פריט/מוצר

| שדה | הגדרה |
|---|---|
| סטטוס | מאושר/נגזר מהקונספט |
| Actor | Regular/Professional |
| תיאור | המערכת תאפשר לפתוח Marketplace Listing או Sponsored Product לקבלת מידע נוסף. מתוך Marketplace Listing פעיל ניתן לפתוח Marketplace Chat עם בעל ה-Listing בהתאם ל-FR-CHAT-002; החריג חל גם כאשר השולח Professional והבעלים Regular. ההתקשרות על Listing היא בצ'אט בלבד (OP-012). **ב-v1 (21.10.2026):** דף המודעה מציג את התמונות שעברו בדיקה (למפרסם גם את שלו שממתינות, מסומנות), הכותרת, המחיר או "למסירה", הקטגוריה, המצב, העיר, שם המפרסם, התיאור (כשנכתב; 26.10.2026) ועד מתי היא מוצגת; אין בו פעולת קנייה או תשלום (AC-097). קורא שולח מהדף הודעה ראשונה (טקסט מוצע שאפשר לשנות): נפתחת שיחת Marketplace עם המפרסם, או ממשיכה השיחה שכבר קיימת ביניהם, והשיחה מציגה את המודעה שממנה נפתחה כל עוד היא זמינה לקורא. אין פנייה על מודעה שנמכרה, הוסתרה או פגה, לא למפרסם עצמו ולא מחשבון צוות. מהדף מדווחים על המודעה (FR-MOD-001), ובדיווח נשמרת הכותרת כפי שהייתה בזמן הדיווח. Sponsored Product מציג קישור לאתר המפרסם (https, בלי שם משתמש בכתובת), שנפתח בכרטיסייה חדשה מחוץ ל-Nestly. |
| תנאים מוקדמים | הפריט זמין. |
| קלט / Trigger | בחירת פריט Marketplace. |
| תהליך מערכת | טעינת פרטי הפריט וסוג המקור. Listing פעיל יכול להציג Message לבעל ה-Listing; Sponsored Product מציג פעולת המשך מסחרית בהתאם להגדרתו. |
| פלט | Marketplace Item Detail ופעולת המשך מתאימה לפי סוג המקור. |
| מצב לאחר ביצוע | נרשמת צפייה/פעולת המשך לפי צורך. |
| בעל אחריות לוגי (Page / Feature) | מסך פריט Marketplace |
