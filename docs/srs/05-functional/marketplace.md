## FR-MKT-001 — צפייה ב-Marketplace

| שדה | הגדרה |
|---|---|
| סטטוס | מאושר/נגזר מהקונספט |
| Actor | Regular/Professional |
| תיאור | המערכת תציג עמוד Marketplace כאוסף פרסומי מוצרים. העמוד יכלול Marketplace Listings שמשתמשים רגילים מפרסמים לצורך מכירה/מסירה, וכן תוכן מסחרי/מוצרים ממומנים לפי המודל העסקי. קופונים ו-Affiliate אינם ב-MVP; בהצגה למרצה מוצגים קופונים לדוגמה, מסומנים כדוגמה (OP-023 נסגר, החלטת אפיק מ-18.10.2026). |
| תנאים מוקדמים | משתמש מחובר. |
| קלט / Trigger | Marketplace Listings, Sponsored Products/Content ונתוני קידום. |
| תהליך מערכת | טעינת פריטים והצגתם לפי סוג המקור והקידום. |
| פלט | רשימת פריטי Marketplace עם זיהוי ברור של סוג הפרסום. |
| מצב לאחר ביצוע | המשתמש יכול לבחור פריט/מוצר. |

|---|---|
| סטטוס | מאושר; עודכן 18.10.2026 (OP-012 נסגר) |
| Actor | Regular User |
| תיאור | המערכת תאפשר למשתמש רגיל ליצור Marketplace Listing נפרדת מפוסט קהילתי רגיל, לצורך מכירה או מסירה של מוצר. **כללי המסחר** (החלטת אפיק מ-18.10.2026, OP-012): מודעה כוללת כותרת, קטגוריה, מצב, מחיר או "למסירה", עיר ותמונות. המוכר מסמן "נמכר/נמסר", ומודעה פגה אחרי 60 יום. ההתקשרות בצ'אט בלבד, בלי תשלום באתר (BR-069). |
| תנאים מוקדמים | משתמש רגיל מחובר. |
| קלט / Trigger | כותרת, קטגוריה, מצב, מחיר או "למסירה", עיר ותמונות (VAL-041). |
| תהליך מערכת | ולידציה ושמירת Listing עם sourceType של משתמש רגיל. |
| פלט | Marketplace Listing חדשה. |
| מצב לאחר ביצוע | הפריט מופיע ב-Marketplace בהתאם לכללי החשיפה, עד שסומן "נמכר/נמסר" או עד שפג אחרי 60 יום. |
| בעל אחריות לוגי (Page / Feature) | MarketplaceFeature |
