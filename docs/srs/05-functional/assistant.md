# 5. דרישות פונקציונליות · Assistant — העוזר של Nestly

## FR-AI-001 — העוזר של Nestly

| שדה | הגדרה |
|---|---|
| סטטוס | מאושר; זמין (החלטות אפיק מ-28.10.2026) |
| Actor | Regular User / Professional User |
| תיאור | המערכת תציע עוזר שיחה מבוסס AI, "העוזר של Nestly", שעונה על שאלות כלליות בתחום תכנון הריון, הריון והורות, בעברית טבעית וניטרלית מגדרית (NFR-USAB-003). העוזר אינו מאבחן ואינו נותן ייעוץ רפואי אישי, ובמצב שעלול להיות דחוף הוא מפנה למוקדי הרפואה (FR-MENU-002). שאלה מחוץ לתחום נענית בהפניה עדינה לנושאים שבתחום. |
| תנאים מוקדמים | משתמש Regular או Professional מחובר ופעיל. Admin, Moderator ואורח אינם רואים את העוזר: אין בועה במסכי הכניסה, ההרשמה והניהול. |
| קלט / Trigger | לחיצה על הבועה הקבועה בפינה הימנית התחתונה של כל מסך במעטפת (PG-062), ואז הקלדת שאלה או בחירה בשאלה לדוגמה. |
| תהליך מערכת | הבועה ממוקמת כך שאינה מכסה את הניווט התחתון בטלפון או את "חזרה למעלה". לחיצה פותחת את חלון העוזר: בראשו "ההודעות נשלחות לשירות של Google לעיבוד. לא נשלח מידע מהחשבון שלכם.", ובתחתיתו שורה קבועה "לא ייעוץ רפואי · במצב דחוף — מוקדי רפואה" עם קישור לעמוד מוקדי הרפואה. בשיחה ריקה מוצגות שאלות לדוגמה. כל הודעה (VAL-053) נשלחת לעיבוד אצל Google (Gemini) יחד עם עד שש הודעות קודמות מאותה שיחה, ובלי שום מידע אחר מהחשבון (NFR-PRIV-008); התשובה מוצגת בחלון כטקסט. הודעה שכוללת מילה דחופה מציגה מיד פס בולט שמפנה למוקדי הרפואה, בלי תלות בתשובה (BR-093). השימוש מוגבל ל-20 הודעות בשעה ול-60 ביום לכל חשבון (BR-092). כשהשירות אינו זמין, איטי או ממצה את המכסה — ERR-055; שאר המוצר אינו מושפע. |
| פלט | חלון שיחה עם ההודעות שנשלחו, התשובות, פס דחוף כשצריך והודעת "לא זמין" כשצריך. |
| מצב לאחר ביצוע | השיחה נשמרת רק בדף הפתוח: היא נשארת כשעוברים בין מסכים וכשסוגרים את החלון, ונעלמת ברענון הדף או ביציאה מהחשבון. דבר מהשיחה אינו נשמר ב-Nestly. |
