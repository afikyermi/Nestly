# docs/design — העיצוב של Nestly

מקור האמת לשפה החזותית. ה-SRS קובע **מה** יש בכל מסך (§4.2, §7), והתיקייה הזו קובעת **איך הוא נראה**.
שינוי בהתנהגות שה-SRS מתאר הוא החלטה של אפיק, והוא נרשם ב-SRS.

| `tokens.md` | ערכי צבע, טיפוגרפיה, ריווח, פינות וצללים, עם טבלת ניגודיות | אחרי R1 |
| `components.md` | מיפוי רכיבי §4.2 למימוש, ומצב כל רכיב | עם 9.7 |
